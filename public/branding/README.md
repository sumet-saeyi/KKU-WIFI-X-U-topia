# U-Ikigai logo exports

Both PNG files preserve the existing four-petal project mark and its original colors. They are 1024 × 1024 pixels.

- [u-ikigai-logo.png](./u-ikigai-logo.png): transparent background, for submission forms and presentations.
- [u-ikigai-icon.png](./u-ikigai-icon.png): the original dark, rounded-square app icon.

Regenerate both from `public/icon.svg` with `npm run logo:export`. The website serves them at `/branding/u-ikigai-logo.png` and `/branding/u-ikigai-icon.png`.
